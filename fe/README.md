# FitJourney Web App

React + TypeScript + Vite. Jalankan dari folder `fe` dengan `npm install`
kemudian `npm run dev`.

Frontend ini menggunakan API Express di folder `be`. Untuk setup environment,
seed data, dan perintah pengembangan, ikuti [README utama](../README.md).

- [Panduan menjalankan proyek](../README.md)
- [Struktur proyek](../docs/ARCHITECTURE.md)

Halaman dan komponen spesifik ada di `src/features/`. Komponen bersama di `src/components/`, service API di `src/services/`, dan URL gambar online di `src/config/images.ts`.
